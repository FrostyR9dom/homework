🔌 API ЭНДПОИНТЫ (бэкенд)
═══════════════════════════════════════════════════════════════════

АВТОРИЗАЦИЯ (/api/auth)
├── POST /send-code          ← Отправить SMS с кодом
├── POST /verify-code        ← Проверить код и войти
├── GET  /me                 ← Данные текущего пользователя
└── POST /update-profile     ← Обновить профиль

МАРШРУТЫ (/api/routes)
├── GET    /                 ← Список (с фильтрами: ?type=&region=&sort=&page=)
├── GET    /:id              ← Один маршрут с отзывами
├── POST   /                 ← Создать (только автор)
├── PUT    /:id              ← Обновить (только автор)
├── DELETE /:id              ← Удалить (только автор)
├── POST   /:id/buy          ← Купить маршрут
├── POST   /:id/favorite     ← Добавить/удалить из избранного
├── GET    /my/created       ← Мои созданные маршруты
└── GET    /my/purchased     ← Мои купленные маршруты

ПОЛЬЗОВАТЕЛИ (/api/users)
├── GET /profile             ← Мой профиль
├── PUT /profile             ← Обновить профиль
├── GET /stats               ← Статистика автора
└── GET /favorites           ← Избранное

ГАЛЕРЕЯ (/api/gallery)
├── GET  /                   ← Список фото
├── POST /upload             ← Загрузить фото
└── POST /:id/vote           ← Голосовать за фото

ФОРУМ (/api/forum)
├── GET  /sections           ← Список разделов
├── GET  /section/:id        ← Темы раздела
├── GET  /topic/:id          ← Тема с сообщениями
├── POST /topic              ← Создать тему
└── POST /topic/:id/reply    ← Ответить в теме


═══════════════════════════════════════════════════════════════════
🚀 КАК ЗАПУСТИТЬ ПРОЕКТ
═══════════════════════════════════════════════════════════════════

1. Установить Node.js (скачать с nodejs.org)

2. Открыть терминал в папке backend/ и выполнить:
   npm install
   npm start

3. Сервер запустится на http://localhost:3000

4. Открыть frontend/index.html в браузере
   (или использовать Live Server в VS Code)

5. Для теста входа:
   - Ввести номер телефона
   - Код появится в ответе сервера (демо-режим)
   - Ввести код и войти



ПОЛЬЗОВАТЕЛЬ ЗАХОДИТ НА САЙТ
         │
         ▼
   ГЛАВНАЯ СТРАНИЦА
   (видит всё: каталог, маршруты, цены)

         │         │
         │         ▼
         │   СТРАНИЦА МАРШРУТА
         │   (видит описание, фото, параметры)
         │         │
         │         ├── Нравится → нажимает "КУПИТЬ"
         │         │         │
         │         │         ├── ГОСТЬ → переход на вход по телефону
         │         │         │         │
         │         │         │         ▼
         │         │         │   ВВОД ТЕЛЕФОНА → ПОЛУЧЕНИЕ КОДА
         │         │         │         │
         │         │         │         ▼
         │         │         │   АВТОМАТИЧЕСКИ ВОЗВРАЩАЕТСЯ НА МАРШРУТ
         │         │         │   И СРАЗУ ВИДИТ ПОДТВЕРЖДЕНИЕ ПОКУПКИ
         │         │         │
         │         │         └── АВТОРИЗОВАН → сразу подтверждение покупки
         │         │
         │         └── Не интересует → идёт дальше
         │
         ├── Смотрит галерею
         │
         ├── Читает форум
         │
         └── Хочет создать маршрут
                   │
